# Five-minute portfolio walkthrough

The hosted UI is an interactive **synthetic sandbox**. The demo is intended to be used in an interview, freelance proposal or GitHub screen recording.

## Step 1 — Observability at a glance (30 seconds)

Open the live HookLedger UI. Explain the summary metrics, 7-day event throughput chart, breakdown chart and live-looking event stream. The metrics derive entirely from generated fixtures and local demo actions — not from external integrations or real users.

## Step 2 — Trace a failure (1 minute)

Go to **Event explorer**, set the status filter to **Failed**, and select a `ticket.created` event from **Support escalation**. Use **JSON payload** to inspect the synthetic input, then open **Execution trace** to show:

1. JSON validation
2. Condition match
3. Route selection
4. Intentional sandbox failure

The failure is not a network outage; it is intentionally generated by a configurable delivery mode.

## Step 3 — Debug and replay (1 minute)

Visit **Routing rules → Support escalation → Configure rule**. Change **Delivery mode** from *Failure laboratory* to *Local archive*, then save. Return to the failed event and click **Replay event**. It should transition from **Failed** to **Archived**, increase the attempt count, and record a replay step.

## Step 4 — Experiment with payloads (1 minute)

Open **Playground**, choose **Lead qualification**, and load the example JSON. Change `"score": 84` to `"score": 12`. Press **Simulate** and observe **Filtered**, with a complete trace, without creating a stored event. Restore the score to 84, click **Send test event** and inspect the newly created event in the stream.

## Step 5 — Show real backend engineering (90 seconds)

Locally, start FastAPI and create a route using the authenticated API. Send a signed payload with `backend/scripts/demo_sender.py`. Reuse the same idempotency key manually to show that the event ID stays the same and the ledger doesn't duplicate records. Run `pytest` to show the concurrency, signature, route validation and replay tests.

## Key distinctions to state

- UI sandbox ≠ production event delivery.
- Archive ≠ forwarded to Stripe, Slack, email or a CRM.
- The backend is a real HTTP API with SQLite storage, but production hardening is still required.
- No AI API or paid SaaS account is necessary to test the project.

## Suggested project pitch

> HookLedger is a webhook reliability console I built to demonstrate robust API integration patterns. It validates signed requests, deduplicates retries, evaluates configurable rules, preserves execution traces and lets operators replay failed events. The React/TypeScript interface includes a local sandbox, and the separate FastAPI backend is covered by integration tests. It's a portfolio lab, not a claim of a production SaaS with paying customers.
