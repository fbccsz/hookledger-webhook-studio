# HookLedger interface captures

These JPEG files are unedited browser captures of the working [HookLedger sandbox](https://hookledger-webhook-studio.vercel.app/), taken on **2026-11-11**. Only built-in fictional fixtures were used. The Python backend was not connected.

| File | View | Reproduction |
| --- | --- | --- |
| [01-overview.jpg](01-overview.jpg) | Operations overview | Open the sandbox and select **Overview**. |
| [02-event-trace.jpg](02-event-trace.jpg) | Failed event trace | Select **Event explorer**, filter status to **Failed**, open **evt_demo_00018**, then select **Execution trace**. |
| [03-routing-rules.jpg](03-routing-rules.jpg) | Rule configuration overview | Select **Routing rules**. |
| [04-playground.jpg](04-playground.jpg) | JSON dry run | Select **Playground**, keep the sample **Lead qualification** payload with score **84**, and select **Simulate**. |

These views share the root URL. Dates and relative event times are generated by the sandbox and may differ on later visits. The failed delivery is intentional demo behavior; the Playground capture is a dry run, with no stored event and no external request.

The images document the actual interface and do not represent production traffic, clients or payment activity.
